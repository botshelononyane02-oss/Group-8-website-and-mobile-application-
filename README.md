Pawsitive Pet Academy Website and Mobile Application

Project Description

Pawsitive Pet Academy is a website and mobile application designed to provide information about pet care and training courses. The platform allows users to explore available programmes, view course information, calculate fees, and contact the academy for further assistance. The project was developed as part of the Work Integrated Learning (XHAW5112) group assignment.

Purpose

The purpose of this project is to create a user-friendly digital platform that helps pet owners and aspiring pet-care professionals access information about training programmes and educational opportunities.
